# Security

## Reporting a problem

Do **not** open a public issue for a security problem. Use GitHub's private reporting: the **Security** tab of this repository, **Report a vulnerability**.

## If you committed a secret by mistake

Report it straight away the same way. Deleting the line in a new commit is not enough, because the secret stays in the history. The key or password must be changed, and the maintainers will clean up.
